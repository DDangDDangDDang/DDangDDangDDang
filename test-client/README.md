# 땅땅땅 테스트 클라이언트

라이브 스트리밍(LiveKit)과 실시간 채팅(STOMP)을 브라우저에서 직접 확인하기 위한 개발용 React 페이지입니다.
실제 서비스 프론트엔드가 아닙니다.

## 준비

1. MySQL, Redis, LiveKit 실행 (저장소 루트에서)

   ```bash
   docker compose up -d mysql redis livekit
   ```

   MySQL을 직접 설치해 쓰고 있다면 `redis livekit`만 띄워도 됩니다.

2. 백엔드 실행 (저장소 루트에서, 기본 포트 8080)

   ```bash
   ./gradlew bootRun
   ```

3. 테스트 클라이언트 실행

   ```bash
   cd test-client
   npm install
   npm run dev
   ```

   브라우저에서 http://localhost:5173 을 엽니다.
   `/api`, `/ws` 요청은 Vite 개발 서버가 `http://localhost:8080`으로 넘깁니다.

   백엔드를 다른 포트로 띄웠다면 `test-client/.env.local` 파일에 주소를 적습니다. (커밋되지 않는 파일)

   ```
   BACKEND_URL=http://localhost:8081
   ```

   백엔드 포트는 `./gradlew bootRun --args=--server.port=8081`처럼 바꿀 수 있습니다.

## 테스트 순서

판매자와 시청자를 동시에 보려면 **일반 창 + 시크릿 창**처럼 쿠키가 분리된 창 두 개를 씁니다.
(같은 브라우저의 탭끼리는 Refresh Token 쿠키를 같이 써서 계정이 섞입니다.)

| 단계 | 판매자 창 | 시청자 창 |
| --- | --- | --- |
| 1 | 회원가입 / 로그인 | 다른 계정으로 회원가입 / 로그인 |
| 2 | 방송 제목 입력 → **방송 만들기** (방송 ID 자동 입력) | |
| 3 | **방송 시작 (판매자)** → 카메라·마이크 권한 허용 → 내 카메라 표시 | |
| 4 | | 같은 방송 ID 입력 → **시청 입장** → 판매자 영상 표시 |
| 5 | **채팅 연결** → 메시지 전송 | **채팅 연결** → 같은 메시지 수신 |
| 6 | **방송 종료** → 영상 연결 끊김 | 채팅에 "방송이 종료되었습니다." 표시, 영상 끊김 |

시청자 쪽에 **소리 켜기** 버튼이 보이면 브라우저 자동 재생 정책 때문이니 한 번 눌러 주세요.

## 확인해 볼 수 있는 동작

| 동작 | 기대 결과 |
| --- | --- |
| 빈 메시지 전송 | `COMMON_001` 에러 (나에게만 표시) |
| 5초 안에 6개 이상 전송 | `LIVECHAT_001` → 이후 `LIVECHAT_002` "N초 후에 다시 보낼 수 있습니다." (30초) |
| 방송 시작 전 채팅 | `LIVESTREAM_004` |
| 30분 뒤 전송 (토큰 만료) | `AUTH_002`로 연결 종료 → 자동 재발급 후 다시 연결 |
| 판매자가 아닌 계정으로 방송 시작·종료 | `LIVESTREAM_002` |

화면 아래 **로그**에 요청 결과와 에러 코드가 쌓입니다.

## 구조

| 파일 | 역할 |
| --- | --- |
| `src/api.ts` | REST 호출, Access Token(메모리) 관리, 만료 시 자동 재발급 |
| `src/AuthPanel.tsx` | 로그인, 회원가입 |
| `src/LivePanel.tsx` | 방송 만들기·조회·시작·시청·종료, LiveKit 송출·시청 |
| `src/ChatPanel.tsx` | STOMP 연결, 채팅 구독·전송, 에러 표시 |
